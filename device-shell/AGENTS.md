# device-shell

Static C++ files providing a human-friendly UART terminal shell for AURA register modules.

## Files

| File | Description |
|------|-------------|
| `reg_shell.hpp` | `RegShellConfig` struct + `RegShell` class declaration |
| `reg_shell.cpp` | Terminal implementation: parser, path resolver, TAB completion, VT100, formatter |

## Usage

```cpp
#include "<mod>_reg_doc.hpp"
#include "reg_shell.hpp"

RegShell shell;

void uart_rx_isr(char c) { shell.feed(c); }

void main() {
    shell.init(module_make_shell_config(uart_tx_char));
}
```

The `<mod>_make_shell_config()` factory is generated by `device-firmware-gen` into
`<mod>_reg_doc.cpp`.  It wires the module's comm functions (`reg_read`, `reg_write`,
`reg_reset`) and ROM doc tables into a `RegShellConfig` that `RegShell` consumes.

## Compile

Include both this directory and the generated output directory on your include path.
Link: `reg_shell.cpp`, `<mod>_reg_doc.cpp`, `<mod>_reg_comm.cpp`, `<mod>_reg_storage.cpp`.

## Configuration macros

| Macro | Default | Description |
|-------|---------|-------------|
| `SHELL_LINE_LEN` | 80 | Max characters per input line |
| `SHELL_HISTORY_DEPTH` | 8 | Number of history entries retained |

## Supported commands

| Command | Alias | Description |
|---------|-------|-------------|
| `help` | `?` | List all commands |
| `ls [group]` | `list` | List registers (filtered to group if given) |
| `r <path>` | `read` | Read register or bit-field value |
| `w <path> <val>` | `write` | Write register (bit-field writes rejected) |
| `d <path>` | `describe` | Show full register metadata |
| `dump` | | Read all readable registers |
| `reset` | | Call reg_reset() |

## Path syntax

```
reg              top-level register
group.reg        register in group
group[2].reg     group instance 2
group.reg[3]     bank element 3
group.reg.field  bit-field (read and describe only)
```
